## 1c. Αληθινές φωτογραφίες προϊόντων — `photos.js` + `props/photo.js` (από το ad_xeimonas)
- Πηγή: οι φωτογραφίες του site (προμηθευτής, π.χ. Roly `…/model/hd/…` 2000×2500). Λίστα `photos/<ep>.txt` (`όνομα URL`) → **`node photos.js <ep>`** → κόψιμο φόντου με macOS Vision (`tools/lift.swift`, χωρίς API) → `photos/<ep>/<όνομα>.webp` (cut-out) + `.jpg` (όπως είναι, για κατάλογο) + `index.json` — στο git (ίδιο αποτέλεσμα σε κάθε render).
- Στο χαρτί: `photoCut()` = cut-out «κομμένο από κατάλογο» (λευκή σκισμένη άκρη, σκιά, boil 12fps) που κινείται σαν χάρτινη κούκλα (spring, αδράνεια). Η φωτογραφία δεν παραμορφώνεται.
- **Logo πάνω στο ύφασμα** (`photoLogo`, οι πτυχές περνάνε στη στάμπα/στο κέντημα): σημείο στήθους διαλεγμένο από **κοντινό της φωτογραφίας** — επίπεδο ύφασμα, μακριά από χέρια, φερμουάρ, κορδόνια, ραφές/τσακίσεις · μέγεθος πραγματικού logo στήθους (~10 cm ≈ 13% του πλάτους της φωτογραφίας) · φούτερ: στάμπα στο κέντρο, ανάμεσα στα κορδόνια και την τσέπη. **Logo μόνο σε κοντινά** (1–2 ρούχα): σε πλάνο ομάδας είναι μικρό και «φαιλ» → χωρίς logo (ad_xeimonas v2 → v3).
- Εναλλαγή προϊόντων: **ίδια κίνηση για όλα** (carousel από χάρτινα πάνελ που γλιστράνε με ελατήριο στη λέξη), όχι διαφορετική είσοδος ανά ρούχο + απότομη αλλαγή φόντου (ad_xeimonas v3: «οι εναλλαγές δεν είναι smooth»). Πλάνο ομάδας στο hook: zoom στο πρώτο ρούχο + αργή κίνηση πάνω στα ρούχα.
